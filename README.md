# SmartLib Library Management System

SmartLib is a library automation system designed to manage books, users, book reservations, borrowing history, returns, overdue records, and statistical reports.

## About the Project

This project was developed as a library management and automation system for an Information Resource Center.  
The system helps librarians and users manage library processes digitally and efficiently.

## Main Features

- Book catalog management
- User management
- Book search and filtering
- Book reservation system
- Borrowing and returning control
- Overdue book tracking
- Faculty-based statistics
- Admin dashboard
- Library activity reports

## Technologies Used

- Python
- Django
- Django REST Framework
- SQLite / PostgreSQL
- HTML
- CSS
- JavaScript
